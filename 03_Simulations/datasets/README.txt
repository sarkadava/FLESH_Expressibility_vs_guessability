FLESH_Expressibility_vs_guessability\03_Simulations\datasets

Here we store datasets associated with simulating scripts

- ppd_matrix.csv - posterior predictive matrix of expressibility estimates per concept/modality
- empty_df.csv - dataframe with concepts per modality listed
- bayesfactor_summary.csv - summary of Bayesian t-test per each simulation type
- posteriors_summary.csv - summary of posterior estimate of a difference + diagnostis per each simulation type

In folder simulation_results/ we store the simulation outputs
