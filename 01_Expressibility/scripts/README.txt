FLESH_Expressibility_vs_guessability/01_Expressibility/scripts

In this folder, we store the following scripts:

01_data_processing.Rmd - This script processes raw data (from folder rawdata),
clean them and prepare them into one df (df_expressibility_dutch_final.csv stored in folder data)

02_expressibility_modelling.Rmd - This script takes df_expressibility_dutch_final.csv and models
the posterior estimates of expressibility for each concept.
