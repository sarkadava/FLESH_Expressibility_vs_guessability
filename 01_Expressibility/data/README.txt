FLESH_Expressibility_vs_guessability/01_Expressibility/data

In this folder, we store all dataframes

- concept_list_info.xlsx - table of all concepts included in the experiment/analysis with translations and semantic info
- df_express_dutch_final.csv - cleaned dataframe prepared by processing script
- df_express_dutch_norm_avg.csv - raw mean expressibility per each concept and modality
- df_estim_dutch.csv - posterior estimates from modelling per concept & modality
